Como os alertas são tratados

Endereços novos são candidatos publicados, não confirmação de um contrato on-chain. Infraestrutura já identificada na análise inicial não dispara como token novo. Alertas persistem após reiniciar. Eventos encontrados juntos são agrupados em uma sequência de oito bipes. O áudio é executado pelo Python no Windows, sem depender de autoplay do navegador. Limites HTTP são respeitados; latência e pausas aparecem nas fontes.
